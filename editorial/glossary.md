# 用語集（記事化・校閲の参照元）

このファイルは **記事ドラフト** と **/koetsu 校閲** の両方が参照する唯一の用語典拠です。
人間が随時更新します。「世界の事実」をここだけに閉じ込め、記事本文には推測を持ち込みません。

- 役割①：Whisper 逐語録のカタカナ表記を正規の英語表記に揃える（固有名詞のブレ防止）。
- 役割②：**as-of（現時点の正式名称）** を持ち、`Fable 5.1` のような非実在名・バージョン誤りを
  校閲が **検知** できるようにする。検知後は「ぼかす／注記／要確認」で処理し、**推測の正解で上書きしない**。

## 2. as-of：現時点で実在する正式名称（最終更新 2026-11-25）

> **更新タイミング**：新モデル発表・改名があったら即更新。ここが古いと校閲が誤検知する。
> 記事は「実験当時に言われた名前」に忠実であればよく、ここは **非実在名を見抜くための物差し** として使う。

### Anthropic / Claude 現行ラインナップ
- ファミリ：**Opus**（最上位）/ **Sonnet**（中位）/ **Haiku**（軽量）/ **Fable**
- 旧世代の疑いが濃い例 → `Claude 3.5 Opus`、`Claude 3.5 Sonnet/Haiku`（3.5系は旧世代。記事化AIが旧知識で付けがち）
- 記事で使う粒度：**バージョンが確証できないときは `Opus`/`Sonnet`/`Haiku`/`Fable` のファミリ名だけ**にする
  （例：「最上位モデル」）。版番号は逐語録＋この表で一致したときだけ付ける。

> **【要確認・as-of 未確定】** 2026-11 収録の一次情報（ai-battle-royale 回の逐語録）では
> `Fable 5.1`（Claude最上位ティア）・`Opus 5.5`・`Sonnet 5.5`・`GPT 6.1` が登壇者から語られている。
> 一方、当初この表に seed した版（Opus 4.8 / Sonnet 4.6 / Haiku 4.5 / Fable 5）はAIの学習時点に基づく値で、
> 一次情報と食い違う。**どちらが正しいかは人間が確定し、この表を更新すること**
> （＝「AIに事実のas-ofを持たせると陳腐化する」ことの実例。版番号はここで一元管理する）。

### 他社（主要のみ。網羅はしない）
- OpenAI = **ChatGPT / GPT 系**、Google = **Gemini**、xAI = **Grok**、**DeepSeek**、**Mistral**、**GLM**（智譜/Zhipu）
- バージョン番号（GPT-4.1、GLM 5.3 等）は **逐語録で明言されている場合のみ** 記載。曖昧なら「GPT系」等にぼかす。
